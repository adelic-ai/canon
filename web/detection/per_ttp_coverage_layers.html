Per-TTP coverage — primitives, atoms, compositions, catch-classes

A technique is covered by a set of distinct checks, not "≥1 rule." Rules and the battery are atoms in one basis; statistics are molecules of arithmetic primitives; the log is read once.

canon · design · 2026-06-19 · one atom IR for rules + battery · independence at the primitive grain

MITRE coverage is usually stated per technique — "do we have a rule for T1003.001?" Wrong granularity. A technique is detected by a set of distinct checks, and coverage is a property of that set. The content-aware signature work proved it: the field-set key collapsed value-distinct checks into one concept and the round fired only one — silently dropping the rest (OTRF T1003.001: 33 field-set concepts → 74 content concepts, 41 distinct detections recovered). So per-TTP coverage is a layered count, and the layer you measure at decides what covered and redundant mean.

1 · The layers — four, and the stack is recursive

primitive        count, sum, divide, log₂, multiply, compare, rank   — the irreducible arithmetic/logical leaf
   │  compose
atom / molecule  a predicate or feature                            — a Sigma clause (near-primitive) OR a
   │  bond (AND / cross-event join on a key)                          statistic like entropy (a MOLECULE of primitives)
rule             block(s) + condition                              — a composition of atoms (the authored unit)
   │  group by what they catch
catch-class      rules firing on the same instances               — the true per-TTP variant set (ground truth)
Statistics are not atomic. Shannon entropy is a molecule: histogram → divide(proportions) → log₂ → multiply → sum → negate. MI, CFAR, conformal all bottom out in the same handful of primitives (count, sum, divide, log₂, multiply, compare, rank). The stack is therefore recursive (the architecture's transparency knob): entropy is one node from outside, an arithmetic sub-DAG from inside. This primitive layer is where the machine-checked tier lives (round-off proofs on the accumulation/log ops) and what Atlas catalogs.

2 · One atom basis — rules and the battery are the same kind of thing

Battery detectors are atoms in the same basis as Sigma clauses — different ops, same primitives. The op ranges over match-ops (contains, endswith, re, cidr, gt/lt) and stat-ops (rarity, entropy, MI, CFAR, count/distinct).

  • Stat-atoms can be multi-field / relational (MI(a,b), joint rarity) and field-discovering (surface which field is anomalous). A discovered field that recurs on confirmed labels is a candidate atom promoted into the rule corpus — the abduction / feature-validation loop.
  • Sigma yaml is a partial frontend. It expresses match clauses + Sigma correlation (value_count, event_count, temporal) for count/distinct/threshold/sequence. Distributional ops (entropy, MI, conformal, CFAR) have no Sigma operator — they are IR-native, reachable only via a Sigma vocab extension or a sibling frontend. Both lower to the same atom IR (IR-as-spine: Sigma is one surface over part of the atom space; the IR is the superset).
Worked example — fan-out is two atoms, half Sigma-expressible. Over one (entity, time-bin) cell the detector computes both distinct = |{i : cᵢ>0}| and entropy = −Σ(cᵢ/N)log₂(cᵢ/N): distinct ≥ N → a Sigma value_count correlation rule (Sigma-expressible); entropy ≥ θ → no Sigma operator (IR-native). Same concept, different ops, used as cross-checks of each other.

3 · The atom-truth artifact — the log is read once

Phase A (data-bound, ONCE):  evaluate the distinct atom-set over the log  →  the ATOM-TRUTH ARTIFACT
Phase B (data-free):         every rule/composition is a fold over the artifact — the log is never re-scanned

The artifact is the log projected onto the atom basis — match-atoms as per-event truth, stat-atoms as per-(entity, window) values. The load-bearing intermediate:

  • Content-addressed → a provenance node. artifact_id = hash(atom-set, log); a verdict walks verdict → composition → artifact → (atoms × raw records). The artifact pins which records it derived from — "how did you know?" stops at a durable object, not a re-scan.
  • CSE at the primitive grain. Shared sub-DAGs → the cell histogram is computed once and feeds entropy and distinct and mean. Identical atoms are one node (Merkle dedup), so more rules firing ≠ more work — the firing-volume worry dissolves.
  • It is the warm-retention object. raw log → artifact (kept) → verdicts (kept); the raw log can age out while the artifact survives — the retention & aging "cells" layer made precise.

Not built: eval_ir re-touches the data per rule; the artifact is the design target of atom factoring (corpus-free engine work — an atom-level content digest is the small addition).

4 · The coverage join — the battery co-fires

The artifact spans both match-atoms (rule-known basis) and stat-atoms (a fuller basis), so the battery is not blind to rule-uncovered space and not a mere consumer of a rule-filtered table — it fires in the same Phase-A pass over its own (windowed, multi-field) atoms. Phase B joins them in the coverage space:

a co-located match-atom firesno match-atom at that location
stat-atom fires CORROBORATE — extra witness (if independent, §5) UNCOVERED area — a rule-blind anomaly → coverage gap OR novel-detection candidate (abduction)
no stat-atom RULE-ONLY — known-bad that looks statistically normal; rules cover what stats miss —

The battery is an additive witness, never subtractive: it raises confidence where it co-locates and surfaces gaps where it fires alone; absence of a battery signal never demotes a rule hit.

5 · Independence at the primitive grain — the corrected story

Catch-set co-membership says two rules catch the same target; it does not say "drop one." Two checks reaching it by independent paths are robust (survive a telemetry gap / rename / evasion). But independence must be tested at the finest (primitive) grain, not at (field, op) — and the content-addressed DAG gives it for free: two checks are independent iff their sub-DAGs are disjoint; a shared primitive is shared evidence.

This corrects a too-loose earlier claim that "same field, different op ⇒ independent witness." It is false when the ops share sub-atoms. distinct and entropy are both folds over the same count-vector → not failure-independent (corrupt the counts, both are wrong). Their value is complementarity — cardinality vs distribution-shape, and they can disagree (10 uniform values → distinct=10, entropy=3.3; 10 with one dominating → distinct=10 but entropy≈0). The disagreement is informative; it is not corroboration.

True corroboration needs disjoint sub-DAGs — e.g. a fan-out atom on one field and a signing-anomaly atom on another, sharing no primitive. Belnap confidence fusion credits only such independent witnesses; the DAG decides which, structurally — closing the architecture's flagged independence question for this domain: independence is decidable by sub-atom disjointness, not assumed.

7 · The model in one picture

per-TTP coverage = a set of catch-classes
   each catch-class = rules (compositions) that catch the same instances
      each rule    = a composition of atoms (clauses & statistics)
         each atom = a molecule of primitives (count, sum, divide, log₂, multiply, compare, rank)
            primitives are SHARED → computed once (content-addressed CSE)
   rules and the battery are atoms in ONE basis (match-ops + stat-ops); Sigma yaml is a partial frontend
   keep >1 check per catch-class IFF their sub-DAGs are disjoint (independent witnesses — decided by the DAG)
One line. A technique is covered by a set of distinct checks; rules and the battery are atoms in one basis; statistics are molecules of shared arithmetic primitives, so read the log once and compose; and redundant checks corroborate only when their sub-DAGs are disjoint — independence decided by content-addressing.
